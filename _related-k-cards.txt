=================== K-21 ===================
title: fail-open / fail-closed 按场景分级
**【项目位置】**
内容审核与审计的失败模式设计（INF-04 D11 ADR / AI-410 ADR-410-08 / RAG R12），对应简历"fail-open / fail-closed 按场景分级"。

**【当时约束】**
① 教育高峰集中在开学与期末，一律拒绝会造成大面积不可用；② 词库加载失败时用上一版本，不空词库运行；③ 审计与计量数据不可删（除到期销毁）。

**【选择与取舍】**
- 内容审核：**普通场景 fail-open**（放行 + 异步补审并留痕），**高风险场景（招生 / 派位 / 安全 / 心理）可配 fail-closed**
- 审计：一律 **fail-closed**（审计写入失败即阻断本次调用，不"先提供服务、后补日志"）
- AI-410：审计 fail-closed，只读副本不可用时明确报错，**绝不切主库**
- 网关配额：配额服务不可用时 fail-closed（拒绝而非跳过校验）

**【不这么选会怎样】**
审计做成"先服务后补"：日志补不上的时候，你已经无法证明这次调用发生过——**"审计可选"等于"审计不存在"**。
AI-410 切主库保可用性：会动摇"只读账号隔离"这一安全假设，一次切换就让整条只读链路的论证作废。

**【面试官会从哪追问】**
1. "为什么审核可以 fail-open 而审计必须 fail-closed？" → 答：审核 miss 一次，后果是"漏拦一条违规内容"，可事后补审追责；审计 miss 一次，后果是"这件事没发生过"，不可追责。**一个是质量问题，一个是证据问题。**
2. "高风险场景为什么是'可配'fail-closed 而不是强制？" → 答：材料用词是"可配"，因为是否 fail-closed 取决于该场景的不可逆程度；但招生/派位/安全/心理四类明确列出，实际等同强制。
3. "配额服务不可用为什么不能跳过？" → 答：网关是唯一能在调用发生前拦住花销的位置；跳过校验 = 预算超支不可挽回（I2）。

**【一句话记忆钩子】**
> **审核可以补，审计不能补——所以审核能 fail-open，审计只能 fail-closed。**

=================== K-17 ===================
title: 三路检索不做分数融合：先合并去重，再统一重排
**【项目位置】**
RAG 检索层（D10 §10.1 / ADR-RAG-06），对应简历"三路检索：权限过滤前置，向量 / 图谱多跳 / 关键词 → 合并去重 → 统一重排"。

**【当时约束】**
① 图谱（NebulaGraph）引入但列为**二期**，MVP 先上向量 + 关键词两路；② 图谱构建失败不阻断向量检索；③ `top_k` 须落在对象矩阵登记区间；④ AI-602 的"三键锁定"（county_code + apply_year + 学段）是**过滤条件不是第三路**（ISSUE-151）。

**【选择与取舍】**
术语定为「向量 ∥ 图谱多跳 ∥ 关键词」，融合方式选"**先合并去重、再统一重排**"，不用原始分数加权（不用 RRF 式分数融合）。
重排模型：BGE-reranker-v2-m3 **本地化部署**（Top50 → Top5），**禁用商用 / 外部重排 API**。

**【不这么选会怎样】**
分数融合（加权求和）的问题：三路分数的量纲与分布完全不同，融合权重没有物理意义，调参只能靠评测刷分，且换语料就失效。交给统一重排模型，是让"相关性判断"由模型在统一语义空间里做一次，而不是在三个不可比的分数上做算术。
用商用重排 API 则**查询内容外发**，直接违反"数据不出省、学生个人信息不得调用境外 API"，无回退路径。

**【面试官会从哪追问】**
1. "为什么图谱放二期？" → 答：图谱建设周期会阻塞 MVP；且先用向量+关键词能验证主体收益。这不是技术妥协，是**交付节奏决策**——MVP 被图谱阻塞的风险大于图谱带来的收益。
2. "AI-602 的三键锁定算不算第三路检索？" → 答：**不算**，它是过滤条件（ISSUE-151）。这个区分很重要：过滤是收窄范围，检索是在范围内找内容，两者混谈会导致 top_k 语义混乱。
3. "重排为什么必须本地化？" → 答：查询内容含学生/学校信息，调用外部 API 即外发；V-21 断言：`rerank_model` 含外部 API 标识的记录 = 0。

**【一句话记忆钩子】**
> **三路分数不可比，所以不做加权——先合并去重，再让一个重排模型在统一语义空间里判一次。**
